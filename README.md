# Malee Commodity & Price Watch

A static dashboard of sugar, packaging, coconut, fruit and THB prices, with a short forecast and alerts against Malee’s 17–19% gross-margin target.

**Live:** https://piyaster11.github.io/malee-commodity-watch/

Figures come from public sources (Malee 3Q26 MD&A, World Bank Pink Sheet, Westmetall / LME, OAE, Bank of Thailand, and others) and are dated and linked on the page. Sample or estimated figures — including example cost-mix weights and any forecast band that is not a public futures curve — are labelled as samples. This is a mock-up for discussion, not a live data feed and not trading advice.

GitHub Pages is served from `docs/` on `main`. The page is a single self-contained `docs/index.html`.
